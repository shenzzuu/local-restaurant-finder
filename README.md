# 🍽️ Local Restaurant Finder Web Application

The **Local Restaurant Finder** is a web-based application designed to help users discover nearby restaurants dynamically based on location and real-time weather conditions.

This project demonstrates API integration, dynamic content rendering, and full-stack web development using PHP and JavaScript.

Developed as an academic project.

## 🎯 Project Objectives

- Provide location-based restaurant discovery
- Integrate external APIs for real-time data
- Dynamically display restaurant information

## 🚀 Key Features

- Search and discover nearby restaurants
- Integration with Google Maps data  
- Dynamic content rendering
- Responsive web interface

## 🌐 API Integration

- **Google Maps Scraper API**  
  Used to retrieve restaurant data based on selected location.

- **Open-Meteo API**  
  Used to fetch real-time weather data to influence restaurant recommendations.

## 🏗️ System Architecture

The application follows a client-server architecture:

1. User selects or inputs location.
2. Backend fetches restaurant data via Google Maps Scraper API.
3. Weather data is retrieved from Open-Meteo API.
4. The system processes and displays results dynamically on the frontend.

## 🔒 Security Considerations

- API keys stored securely in configuration files
- Server-side validation of user inputs
- Controlled API request handling

## ⚠️ Project Status

This project was developed for academic purposes and used temporary API and hosting configurations.

Please note:
- Some API integrations may no longer function due to expired API keys or service limits.
- Live restaurant and weather data may not be retrievable in the current demo version.
- The system can be restored by configuring valid API credentials.

## 🔧 Local Setup Instructions

1. Clone the repository.
2. Install XAMPP and start Apache & MySQL.
3. Configure API keys in the configuration file.
4. Run the project on localhost.
